# Mise en bol : mettre en ligne avec GitHub Pages

Pas besoin d'un nouveau compte : ton compte GitHub actuel suffit. Il faut juste un **nouveau dépôt** (repository), séparé de celui de ton planning. Chaque dépôt a sa propre adresse, donc les deux projets n'ont aucun lien.

## Étapes (sur le site github.com, sans rien installer)
1. Connecte-toi, puis clique sur **+** (en haut à droite) > **New repository**.
2. Nom : `mise-en-bol`. Choisis **Public** (GitHub Pages gratuit fonctionne avec les dépôts publics ; vérifie les conditions actuelles de ton offre pour un dépôt privé). Valide avec **Create repository**.
3. Clique sur **uploading an existing file**, puis glisse **tous les fichiers de ce dossier** (index.html, manifest.webmanifest, sw.js, icon.svg). Valide avec **Commit changes**.
4. Va dans **Settings > Pages**. Sous *Build and deployment*, choisis **Deploy from a branch**, branche **main**, dossier **/ (root)**, puis **Save**.
5. Attends 1 à 2 minutes. L'adresse sera : `https://TON-PSEUDO.github.io/mise-en-bol/`

## Sur téléphone
Ouvre l'adresse puis « Ajouter à l'écran d'accueil » : l'app s'ouvre comme une vraie application et marche sans connexion.

## À savoir
- Rien de secret dans ce dossier : tout est public. Aucune clé, aucun serveur.
- Tes recettes enregistrées restent dans le navigateur de l'appareil. Utilise Réglages > Exporter de temps en temps.
- Pour mettre à jour l'app plus tard : remplace les fichiers dans le dépôt (Add file > Upload files).
